# 🏠 Квартирный вопрос: Суздаль

Одностраничная игра по реальным объявлениям посуточной аренды Суздаля: угадывай цены — почувствуй себя риелтором, который всё ещё платит ипотеку.

**Слоган:** «Угадай цену — почувствуй себя риелтором, который всё ещё платит ипотеку»

## Как играть

1. 10 раундов × 10 карточек с реальными объявлениями (Авито, ноябрь 2026).
2. В каждой карточке — фото, адрес, факты и слайдер оценки цены.
3. Жмёшь «Оценить» → узнаёшь настоящую цену и свою ошибку в процентах.

## Очки

| Отклонение от реальной цены | Очки |
|---|---|
| ≤ 5% | 10 |
| 5–15% | 7 |
| 15–30% | 4 |
| 30–50% | 2 |
| > 50% | 0 |

## Вердикты

По медиане отклонений за всю игру:

- 🎯 **Адекватный квартирант** — почти угадываешь
- 💸 **Транжира** — стабильно завышаешь (плюс расчёт переплаты за 10 ночей)
- 🐷 **Экономный гость** — стабильно занижаешь

## Технологии

- Чистые HTML + CSS + JS, без сборки и бэкенда
- Данные объявлений встроены в `script.js`
- Ленивая загрузка фото, карусель, слайдер цены
- Мобильный дизайн (адаптация от 375×667), стиль HSE.ru

## Деплой

Статика для GitHub Pages — просто включи Pages на ветке `main` (root).
